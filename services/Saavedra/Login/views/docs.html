Documentación

A diferencia de los frameworks completos, Saavedra cuenta con poca documentación, ya que basta con conocer algunas funciones reutilizables dentro del código base. Estas se dividen en dos partes principales: Backend ( Go ) y Frontend ( JS | HTML ). A continuación, se dará una breve explicación de cada componente, acompañada de un ejemplo de cómo implementarlo en el código.

( Go ) Backend

Protejer Endpoint ( AuthMiddleware )

Cuando se programan endpoints ( aplicación ) siempre se debe protejer la ruta envolviendo el endpoint con un AuthMiddleware además de protección podra a acceder a data del usuario que realiza la petición. 


                        mux.Handle("/users", utils.AuthMiddleware(http.HandlerFunc(handler.CallUsers)))

Data Del Usuario en Petición ( type ContextKey )

Es posible acceder a la data de usuario cuando se realiza una peticion a algun endpoint ( protejido ). A continuacion se muestra la posible data: 


                        // Id ( Base de datos ) del usuario

                        id := r.Context().Value(utils.UserId).(string)

                        // Name ( Base de datos ) del usuario
                        name := r.Context().Value(utils.UserName).(string)

                        // Grupo de permisos del usuario
                        party := r.Context().Value(utils.UserParty).(string)

                        // Token JWT de autenticidad
                        jwt := r.Context().Value(utils.UserToken).(string)

Obtener Data de Usuario Sin Protejer Endpoint ( LowLevelMiddleware )

Si se desea obtener data de usuario desde el Context( ) de la petición sin protejer un endpoint, es posible usar LowLevelMiddleware. 


                        mux.Handle("/session", utils.LowLevelMiddleware(http.HandlerFunc(handler.CallSession)))

Permisos de Usuario ( AddPermissions )

Ademas de la protección de endpoints, existen los permisos. Puedes agregar permisos según el grupo de ususario ( party ) para, leer, crear, editar o eliminar registros de la siguiente manera. Toma en cuenta que los componentes JS se encargan de manejar no autorizados. Argumentos:

  • Int Nivel de permiso: si 0 se asume 4
  • String Grupo del usuario obtenido desde .Contex()

                        party := r.Context().Value(utils.UserParty).(string)
                  		valid, err := utils.AddPermissions(0, party)
                  		if err != nil {
                 			log.Printf("Error '/users' (%v)", err.Error())
                 			http.Error(w, err.Error(), http.StatusInternalServerError)
                 			return
                  		}
                  		if !valid {
                 			w.WriteHeader(http.StatusUnauthorized)
                 			return
                  		}

Contar total de pagínas ( CalculateTotalPages )

En algunos casos es necesario contar las pagínas segun la cantidad de filas determinadas por un slice enviado al frontend. Esto permite determinar si una pagina de registros tiene una pagina siguiente. 


                        // La función tiene 2 argumentos:
                        // 1. Filas totales
                        // 2. Total de filas enviadas al frontend
                        totalPages := utils.CalculateTotalPages(count, utils.RecordsPerSlice)

Variables de entorno ( .env )

Además de las filas que se envian al frontend, existen otras variables que determinan procesos del backend. 


                        // Protección ( Token )
                        SESSION_TOKEN=
                        // Nombre de la base de datos
                        DATABASE_NAME=
                        // Nombre del administrador
                        ADMIN_NAME=
                        // Correo del administrador
                        ADMIN_EMAIL=
                        // Contraseña del administrador
                        ADMIN_PASSWORD=
                        // Registros enviados al frontend por petición
                        RECORDS_PER_SLICE=
                        // Obtencion de peticiones seguras unicamente
                        IS_PRODUCTION=
                        HOST=
                        PORT=
                        // Tiempos de expiración determinadas en frontend y backend
                        BACKEND_TOKEN_EXPIRATION_TIME=
                        FRONTEND_TOKEN_EXPIRATION_TIME=

Navegación ( GoHome, GoBack, logOut, OnlyRedirect )

En esta sección se muestran 4 reutilizables de JavaScript que permiten redireccionar y navegar sin tener que programar desde 0. El uso es extremadamente simple; el componente Alpine lo incia en el HTML, los mapeas con minuscula, y llamas a la funcion en mayusculas. Estas funionen ya se encargan de la seguirdad y sesión de usuario. 


                        // Unicamente GoBack y OnlyRedirect requieren del argumento "path"
                        // un string de la ruta de redirección.
                        async goHome() { await GoHome() },
                        async goBack() { await GoBack(path) },
                        async logOut() { await LogOut() },
                        async goUsers() { await OnlyRedirect(path) },
