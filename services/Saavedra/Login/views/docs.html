Documentación

A diferencia de los frameworks completos, Saavedra cuenta con poca documentación, ya que basta con conocer algunas funciones reutilizables dentro del código base. Estas se dividen en dos partes principales: Backend ( Go ) y Frontend ( JS | HTML ). A continuación, se dará una breve explicación de cada componente, acompañada de un ejemplo de cómo implementarlo en el código.

( Go ) Backend

Protejer Endpoint ( AuthMiddleware )

Cuando se programan endpoints ( aplicación ) siempre se debe protejer la ruta envolviendo el endpoint con un AuthMiddleware además de protección podra a acceder a data del usuario que realiza la petición. 


                    mux.Handle("/users", utils.AuthMiddleware(http.HandlerFunc(handler.CallUsers)))

Data Del Usuario en Petición ( type ContextKey )

Es posible acceder a la data de usuario cuando se realiza una peticion a algun endpoint ( protejido ). A continuacion se muestra la posible data: 


                    // Id ( Base de datos ) del usuario

                    id := r.Context().Value(utils.UserId).(string)

                    // Name ( Base de datos ) del usuario
                    name := r.Context().Value(utils.UserName).(string)

                    // Grupo de permisos del usuario
                    party := r.Context().Value(utils.UserParty).(string)

                    // Token JWT de autenticidad
                    jwt := r.Context().Value(utils.UserToken).(string)
